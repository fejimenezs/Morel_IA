# 🧠 Morel-IA

> **"Inteligencia artificial con alma para transformar la salud mental."**

**Morel-IA** es una plataforma integral diseñada para **psicólogos y coaches** que utiliza Inteligencia Artificial para automatizar tareas administrativas y potenciar la conexión humana.

Nuestra solución graba, transcribe y analiza sesiones de terapia, proporcionando **insights emocionales (Sentiment Analysis)** y resúmenes clínicos automáticos. Esto permite a los profesionales reducir su carga operativa y enfocarse 100% en sus pacientes.

🚀 **Proyecto desarrollado para el reto "CodeUp Riwi: Beyond Limits".**

## 🛠 Tech Stack

El proyecto implementa una arquitectura robusta y escalable:

* **Frontend:** Next.js (UX/UI interactiva y responsiva).
* **Backend:** Node.js + Express (API RESTful segura).
* **AI Microservice:** Python (Procesamiento de audio y NLP).
* **Database:** PostgreSQL (Persistencia de datos relacional).
* **Analytics:** Dashboards de datos integrados.
